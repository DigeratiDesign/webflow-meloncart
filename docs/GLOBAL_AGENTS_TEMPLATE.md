# Global Codex Working Agreements

- Prefer small, reviewable changes.
- Read the repository's root AGENTS.md before modifying code.
- Use the package manager and scripts already present in the repository.
- Do not add production dependencies without asking.
- Do not change build tooling, linting, formatting, or TypeScript configuration unless the task requires it.
- Do not commit, push, rebase, reset, or force-push unless explicitly requested.
- Run available validation after code changes and report exactly what ran.
- Avoid unrelated cleanup while implementing a focused task.
- When migrating known-working code, preserve behaviour first and refactor second.
